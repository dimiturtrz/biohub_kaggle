# Bracketing the score: linking is solved, detection is the whole budget

*2026-07-23 — `biohub_kaggle-dll`, on validation fold 0 (41 held-out videos, stratified by prefix).*

## The two bounds

| arm | what it is | edge Jaccard | full score |
|---|---|---|---|
| **ceiling** | link the ground-truth nodes with the NN linker | **0.998** | — (see below) |
| **floor** | classical LoG detector + the same NN linker | **0.55** | 0.56 |

The gap is **~0.44 of edge Jaccard, and essentially all of it is detection.** Nearest-neighbour linking
of perfect detections already reaches 0.998; swapping perfect detections for a classical detector's is
what costs the 0.44. Effort goes into detection, not linking.

The ceiling's full score is not quoted because it is not comparable: the ceiling links only the ~6 % of
cells that are annotated, so its node count is far below the estimate and the node-count term hands it an
unrepresentative bonus (see `2026-07-23_metric-shape.md`). Its *linking quality* is the 0.998 edge
Jaccard. The floor detects to a realistic count, so its adjusted score is meaningful and quoted.

## Ceiling: the linker is not the bottleneck

`python -m celltrack.bracket --arm ceiling` links the GT nodes directly. Edge Jaccard by link gate:

| gate (µm) | edge Jaccard | FN | note |
|---|---|---|---|
| 7 | 0.980 | 491 | loses links that move past the matching cutoff |
| 10 | 0.995 | 115 | |
| **15** | **0.998** | 48 | chosen default |
| 25 | 0.997 | 52 | wrong cells start winning in dense frames |

The gate belongs *above* the 7 µm matching cutoff: a true successor can move further than the matcher
tolerates (motion p99 = 8.38 µm), and until a wrong cell in a crowded frame becomes the cheaper partner,
reaching further only helps. The residual ~0.2 % is structural — a one-to-one assignment gives each parent
a single child, so the second daughter edge of every division is a false negative the NN linker *cannot*
recover. That is the specific thing a division-aware learned linker (`biohub_kaggle-cdo`) has to beat, and
it is small: linking is close to solved for everything except divisions.

## Floor: the classical detector under-detects, and that is the signal

`python -m celltrack.bracket --arm floor` on a stratified 6-video sample: edge Jaccard 0.55, score 0.56,
with **52 k nodes predicted against a 142 k estimate** — the detector found only ~37 % of the target cell
count. It was asked for the estimated number and could not produce it: single-scale LoG peaks with an
anisotropic non-max-suppression footprint do not find that many separated maxima, because many cells are
dim or packed closer than the suppression radius. The under-count then earns a small node-count bonus,
which is why the score (0.56) edges above the raw edge Jaccard (0.55).

So the floor is loose for two compounding reasons, both detection: it misses more than half the cells, and
the cells it does find are placed well enough to link (linking is not the problem) but not densely enough
to cover the annotated lineages. The detector's recall, not the linker's assignment, is what a learned
model has to lift.

## What this decides

- **Detection first.** The learned detector (`biohub_kaggle-3ws`) owns the 0.44 gap; the linker owns at
  most the ~0.002 the ceiling leaves plus whatever divisions add. Build detection before linking.
- **Recall, not precision.** The floor's failure is missed cells (52 k of 142 k), and the metric makes
  recall in unannotated tissue free — so the detector should be pushed toward recall and its operating
  point set by the node-count sweep (`biohub_kaggle-sct`), not by a detection F1.
- **The linker baseline is good enough to reuse.** At 0.998 on perfect detections, the NN linker is a fair
  fixed back-end for evaluating detectors in isolation until the division-aware linker exists.

## Reproduce

```
python -m celltrack.bracket --arm ceiling --fold 0            # ceiling, all 41 validation videos
python -m celltrack.bracket --arm floor   --fold 0 --floor-per-prefix 3   # floor, 6-video sample
python tools/derive_scale.py                                  # the 4.0 µm cell scale the detector uses
```

The floor is sampled because a full LoG pass over 41 videos × 100 frames is slow; the sample is
stratified by acquisition so both prefixes are represented. A full-split floor and a per-prefix
breakdown are follow-ups, not needed to read the gap.
